# 風景 — Fuukei

世界の風景写真を全画面で流し続ける、バックエンド不要の PWA ビューア。
カテゴリとラベルを選ぶと、その条件に合うクリエイティブ・コモンズ / パブリックドメインの
高解像度写真を取得して、スクリーンセーバーのように表示し続けます。

## できること

- **カテゴリ × ラベル × 雰囲気** の 3 段で条件を指定（例: 山岳 × 雪山 × 夕暮れ）
- **全画面表示**。全画面中は Screen Wake Lock API でスリープ / スクリーンセーバーを抑制
- **バックエンド無し**。静的ファイルのみ。API キーが必要なのは AI 生成モードだけ
- **PWA**。インストール可能、オフラインでもキャッシュ済みの写真で再生を継続
- **AI 生成モード**（追加機能）。ユーザー自身の API キーで風景を生成
- **環境音**。雨・焚き火・川・波・風をブラウザ内でその場で合成（音声ファイル不要）。
  複数を重ねて、それぞれ音量を調整できる
- クロスフェード、Ken Burns 効果、時計表示、クレジット表示、キーボード / スワイプ操作

### 操作

| キー | 動作 |
| --- | --- |
| `Space` | 再生 / 一時停止 |
| `←` `→` | 前 / 次の画像 |
| `F` | 全画面 |
| `S` | 設定パネル |
| `I` | クレジット表示の切り替え |
| `M` | 環境音のミュート |
| `Esc` | パネルを閉じる |

タッチ環境では左右スワイプで前後に移動します。3.5 秒操作がないと UI は自動的に消えます。

## 画像ソース

| ソース | APIキー | 備考 |
| --- | --- | --- |
| **Wikimedia Commons**（既定） | 不要 | CC / パブリックドメインのみ。CORS 対応。枚数が最も多い |
| **Openverse** | 不要 | 匿名利用はレート制限が厳しいため予備扱い |
| **AI 生成** | 必要 | Google Imagen / Gemini 画像モデル / OpenAI Images |

Commons では検索時に `filetype:bitmap` と `filew:>1920` で絞り込んだうえで、
取得したメタデータの実寸・アスペクト比・MIME をクライアント側で再検査しています
(`js/sources/commons.js`)。地図や図表・文書スキャンはファイル名で除外します。

作者名とライセンスは画面左下に常時表示できます。**CC BY 系のライセンスは表示が条件**なので、
個人的な鑑賞以外の用途ではクレジット表示を切らないでください。

## 環境音

雨・焚き火・川・波・風の 5 種類を、設定パネルの「環境音」から選んで重ねられます。
複数同時に鳴らせて、それぞれ個別の音量スライダーと、全体の音量・ミュート（`M` キー）があります。

**音声ファイルは一切使っていません。** すべて Web Audio API でその場で合成しています
（`js/audio/`）。ノイズにフィルタをかけて雨や川の質感を作り、焚き火のパチパチや川の泡は
`ctx.currentTime` 基準の先読みスケジューラでランダムに発生させています。そのため

- リポジトリへの追加容量はゼロ
- 第三者の音源を含まないので著作権表示は不要
- オフラインでも（Service Worker のキャッシュ対象外でも）そのまま鳴る

というメリットがあります。

ブラウザの自動再生制限により、AudioContext はユーザー操作なしでは鳴らせません。
前回オンにしていた環境音があっても、ページを開いた直後は無音で、画面をどこか一度
操作（タップ / クリック / キー入力）すると鳴り始めます。iPhone / iPad では本体側面の
消音スイッチが入っていると、この方式の音声は鳴らない点にも注意してください。

## 「画像は都度取得」の設計について

要件にあった「都度取得（要検討）」は、そのまま毎回ネットワークから取り直すと
切り替えのたびに待たされ、通信量も無駄になるため、次の 4 段構えにしました
（実装は `js/playlist.js`）。

1. **検索メタデータ**は取得のたびに IndexedDB へ 24 時間キャッシュ。同じ条件での再訪が速くなる
2. **画像バイナリ**は Service Worker が上限 120 件の LRU でキャッシュ（`sw.js`）
3. 常に **数枚先まで先読み + デコード**しておくので切り替えが引っかからない
4. 通信できないときは、蓄積した「プール」のうち **実体がキャッシュにある画像**を優先して再生

つまり「新しい画像は都度取りに行くが、一度見たものは取り直さない」という方針です。
検索オフセットは総ヒット数からランダムに選ぶので、同じ条件でも毎回違う写真が出ます。
キャッシュは設定パネルの「キャッシュを削除」からいつでも消せます。

## AI 生成モード

設定パネルの「ソース → AI 生成」で有効になります。プロバイダとモデル、API キーを入力してください。

| プロバイダ | 既定モデル | エンドポイント |
| --- | --- | --- |
| Google Imagen (Gemini API) | `imagen-4.0-generate-001` | `generativelanguage.googleapis.com` |
| Google Gemini 画像モデル | `gemini-2.5-flash-image` | 同上 |
| OpenAI Images | `gpt-image-1` | `api.openai.com` |

モデル名は自由入力なので、新しいモデルが出たら差し替えるだけで使えます。

- API キーは **この端末の localStorage にのみ**保存され、生成リクエスト以外には使われません。
  共用端末では使用後に「キーを削除」してください
- ブラウザから直接呼ぶため、プロバイダ側が CORS を許可していないとエラーになります
- 生成 1 枚ごとにプロバイダの従量課金が発生します

## デプロイ

GitHub Pages を使います（ビルド不要の静的サイトなので最短）。

1. リポジトリの **Settings → Pages → Source** を **GitHub Actions** に設定
2. `main` に push すると `.github/workflows/deploy.yml` が動き、
   `https://<ユーザー名>.github.io/<リポジトリ名>/` に公開されます

すべてのパスが相対 (`./`) なので、サブディレクトリ配信でもそのまま動きます。
Cloudflare Pages / Netlify / Vercel にディレクトリごと置いても同様に動作します。

> Service Worker は HTTPS（または `localhost`）でのみ動きます。`file://` で開くと
> PWA 機能が無効になるだけで、表示自体は動きます。

## ローカルで動かす

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

ビルドも依存パッケージもありません。素の ES モジュールだけで構成しています。

## 構成

```
index.html            画面の骨組み
css/style.css         スタイル
sw.js                 Service Worker（アプリシェル + 画像 LRU キャッシュ）
manifest.webmanifest  PWA マニフェスト
js/
  app.js              UI の組み立てとイベント配線
  categories.js       カテゴリ / ラベル / 雰囲気 / 画風の定義
  playlist.js         取得・先読み・履歴・オフライン fallback
  viewer.js           クロスフェードと Ken Burns
  settings.js         設定の永続化
  cache.js            IndexedDB キャッシュ
  wakelock.js         スリープ抑制（Wake Lock + 動画フォールバック）
  fullscreen.js       全画面
  audio/
    engine.js         AudioContext とレイヤー管理（唯一 ctx を持つ）
    sounds.js         音源レジストリ（雨 / 焚き火 / 川 / 波 / 風）
    noise.js          ノイズバッファ生成（純関数）
    scheduler.js      ctx.currentTime 基準の先読みスケジューラ
  sources/
    commons.js        Wikimedia Commons 検索
    openverse.js      Openverse 検索
    ai.js             AI 画像生成
```
